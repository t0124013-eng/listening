# リスニング ラボ

大学入試レベル（共通テスト＋難関国公立二次）の英語リスニングを、1セット約10分で練習するWebアプリ。
メモリーポット スクールと同じ見た目・学びの木・連続日数のしくみを使っています。

## 1セットの流れ（約10分）
| パート | 内容 | 読み上げ | 解答時間 |
|---|---|---|---|
| Part A | 短い発話 ×3問（倒置・仮定法・比較など） | 最大2回 | 各10秒 |
| Part B | 対話 ×2問（意図・結論・理由） | 最大2回 | 各15秒 |
| Part C | 講義 約240語 ×設問3つ | 最大2回（先に設問を読む30秒） | 40秒 |

- 1回目は自動で流れます。聞き終わると「もう1回聞く」ボタンが出て、もう1回だけ聞けます。
- 選択肢を選べば、音声の途中でも「決定して次へ」で進めます。
- 「字幕」をONにすると、読んでいる文がポップアップで表示され、読んでいる場所がカラオケのようにマーカーで追えます（設定は次回も残ります）。ふりかえりの ▶ 再生でも同じマーカーが出ます。
- 2回聞いた問題・字幕を使った問題は、ふりかえりと先生への報告に記録されます。
| ふりかえり | 文ごとの再生・英文かくし・解説・重要語句 | — | — |

ふりかえりで ＋ を押した文・語句は「ふくしゅうカード」にたまり、聞く→まねる→めくる で復習できます。

## 公開のしかた（GitHub Pages）
1. 新しいリポジトリ（例：`listening`）を作り、このフォルダの中身をすべてアップロード
   （`build/` フォルダは編集用なので上げなくてもOK）
2. Settings → Pages → Branch を `main` / `(root)` にして保存
3. `https://<ユーザー名>.github.io/listening/` で開けます

## 先生への報告（任意）
1. `apps-script.gs` の先頭に書いた手順で、スプレッドシートに Apps Script をデプロイ
2. 表示された URL を `index.html` の `const REPORT_URL = '';` に貼る
3. 生徒が結果画面の「先生に報告する」を押すと、1人・1日・1セット1行で記録されます
   （列：日付・クラス・番号・名前・セット・得点・A/B/C別・所要時間・何回目・連続日数・XP など）

## セットを増やす
`sets.js` の配列の最後に、既存のセットと同じ形で書き足すだけです（index.html の編集は不要）。
- `lines` の話者は `'M'`（男性の声）か `'W'`（女性の声）
- `ans` は正解の番号（1番目＝0）
- 更新したら `sw.js` の `VERSION` を1つ上げる（生徒の端末に新しい問題が届きます）

## 音声について
端末の読み上げ機能（Web Speech API）を使うので、音声ファイルは不要です。声の種類と自然さは端末で変わります。
声は端末の標準的な英語の男性・女性の声を自動で使います。「読む速さ」で速さ（ゆっくり／標準＝共通テスト程度／速め）を選べます。
英語の声が入っていない端末では、端末の設定で英語の音声を追加してください。

## 編集用ファイル（build/）
`app.html`・`app.css`・`app.js` を直して `python3 build/build.py` を実行すると `index.html` が作り直されます。
