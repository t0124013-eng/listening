# リスニング ラボ

大学入試レベル（共通テスト＋難関国公立二次）の英語リスニングを、1セット約10分で練習するWebアプリ。
アプリを開くと表紙が出て、「はじめる」でセット選択の画面に進みます。ホームでは連続日数・今日のセット数・解いたセット数・正答率を確認できます。

## 1セットの流れ（約10分）
はじめに「1回聞く（本番モード）」か「2回聞く（練習モード）」を選んでスタートします。どの問題も選んだ回数だけ自動で流れます。

| パート | 内容 | 読み上げ前 | 解答時間 |
|---|---|---|---|
| Part A | 短い発話 ×3問（倒置・仮定法・比較など） | 選択肢を読む5秒 | 各10秒 |
| Part B | 対話 ×2問（意図・結論・理由） | 状況と選択肢を読む5秒 | 各15秒 |
| Part C | 講義 約240語 ×設問3つ | 設問を読む30秒 | 40秒 |
| ふりかえり | 1問ずつ：答えと解説・スクリプト（文タップで再生）・重要語句 | — | — |

- 選択肢を選べば、音声の途中でも「決定して次へ」で進めます。
- 一時停止中も問題と選択肢は見えたままです。
- 「字幕」をONにすると、読んでいる文がポップアップで表示され、読み進めた部分に蛍光ペンが引かれていきます。
- ふりかえりで ＋ を押した文・語句は「ふくしゅうカード」へ。カードは1回タップで音声、もう1回タップで答え（語句は意味と本文の例文）。

## 公開のしかた（GitHub Pages）
1. 新しいリポジトリ（例：`listening`）を作り、このフォルダの中身をすべてアップロード
   （`build/` フォルダは編集用なので上げなくてもOK）
2. Settings → Pages → Branch を `main` / `(root)` にして保存
3. `https://<ユーザー名>.github.io/listening/` で開けます

## 結果の自動記録（先生の管理用スプレッドシート）
記録用のスプレッドシート「リスニング ラボ 記録」の「はじめに」シートに、同じ手順が書いてあります。
1. スプレッドシートの「拡張機能」→「Apps Script」に `apps-script.gs` の中身を貼り付けて保存
2. 関数「setupSheets」を選んで「実行」し、承認画面で「許可」（集計シートに式が入ります）
3. 「デプロイ」→「新しいデプロイ」→ ウェブアプリ（実行：自分／アクセス：全員）
4. 表示された URL を `index.html` の `const REPORT_URL = '';` に貼って GitHub に上げ直す
5. 生徒は最初のセットを始めるときに、クラス・番号・名前を1回だけ登録します。以後はセットを終えるたびに自動で記録されます
   - 通信できないときは端末に残し、次に通信できたときに自動で送り直します
   - 同じ結果が二重に記録されることはありません

スプレッドシートには3つのシートができます。
- **記録**：1セット1行（日時・クラス・番号・名前・セット・得点・正答率・A/B/C別・聞く回数・字幕・所要時間・読む速さ・連続日数 など）
- **生徒別まとめ**：生徒ごとの解いた回数・直近7日の回数・平均正答率・パート別正答率・本番モードの回数・最終利用日、「1週間以上使っていない」「正答率が低め」の目印
- **セット別まとめ**：セットごとの解いた人数・平均正答率・パート別正答率

まとめのシートは記録を集計する式でできているので、記録が増えると自動で更新されます。式が壊れたときは、メニュー「リスニング ラボ」→「集計シートを作り直す」で元に戻せます。

## セットを増やす
`sets.js` の配列の最後に、既存のセットと同じ形で書き足すだけです（index.html の編集は不要）。
- `lines` の話者は `'M'`（男性の声）か `'W'`（女性の声）
- `ans` は正解の番号（1番目＝0）
- `vocab` は `[語句, 意味, 本文の例文]`。例文はふりかえりとカードの裏に出ます
- 更新したら `sw.js` の `VERSION` を1つ上げる（生徒の端末に新しい問題が届きます）

## 音声について
端末の読み上げ機能（Web Speech API）を使うので、音声ファイルは不要です。声の種類と自然さは端末で変わります。
声は端末の標準的な英語の男性・女性の声を自動で使います。「読む速さ」で速さ（ゆっくり／標準＝共通テスト程度／速め）を選べます。
英語の声が入っていない端末では、端末の設定で英語の音声を追加してください。

## 編集用ファイル（build/）
`app.html`・`app.css`・`app.js` を直して `python3 build/build.py` を実行すると `index.html` が作り直されます。
